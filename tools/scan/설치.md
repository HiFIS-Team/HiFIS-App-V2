# 지점 출퇴근 스캐너 설치

지점 카운터 PC 에 **화면 없이** 도는 프로그램을 얹는다. HiFIS 앱을 켜 둘 필요가
없다 — 그 PC 는 회원 등록 등에 같이 쓰는 공용 컴퓨터라, 사람 계정으로 켜 두면
누구나 급여·사내톡·조직도를 들여다볼 수 있고 MASTER 로 켜 두면 모니터링까지 열린다.

**설치할 것이 없다.** 윈도우에 기본으로 있는 PowerShell 로 돈다 —
Flutter 도 Git 도 필요 없다.

---

## 현장 체크리스트 — 지점에 도착해서 순서대로

**빨리 실패하는 순서다.** 3번에서 막히면 아래는 볼 필요가 없다.

### 1. 스캐너를 PC 에 꽂는다

### 2. 설정 바코드로 **USB CDC** 를 읽힌다

기기와 같이 온 설정 종이의 `Interface Setting → USB CDC`.
읽히면 **소리가 평소와 다르게** 난다 (여러 음 = 설정이 먹었다는 뜻).
읽히는 순간부터 **메모장에 글자가 안 찍힌다** — 그게 모드가 바뀐 증거다.

### 3. COM 포트가 잡혔는지 — 여기가 관문

```powershell
[System.IO.Ports.SerialPort]::GetPortNames()
```

`COM3` 같은 게 나와야 한다. **안 나오면 아래를 진행하지 말고** 장치 관리자를
열어 어디에 잡혔는지 본다 (`포트(COM & LPT)` / `키보드` / `기타 장치`).

### 4. 설치 — 관리자 PowerShell 에 붙여넣기

> 시작 → PowerShell **우클릭 → 관리자 권한으로 실행**

**파일 내용을 직접 붙여넣는다.** txt 를 열고 `Ctrl+A` → `Ctrl+C` → PowerShell 에
우클릭으로 붙여넣기다. `설치됨.` 이 뜨면 성공.

> ⚠️ **경로로 부르지 않는다.** `Get-Content "$env:USERPROFILE\Downloads\설치-화순.ps1.txt"`
> 같은 명령을 붙여넣으면 **`Downloads` 뒤의 `\` 가 먹혀서** `Downloads설치-화순...`
> 이 되어 매번 `경로는 존재하지 않으므로` 로 실패한다 (2026-08-07 세 지점에서 다 겪었다).
> 한글 파일명 앞의 역슬래시가 붙여넣기에서 사라지는 것이라, 경로를 안 쓰는 게 답이다.

**그 지점 파일인지 확인한다.** 다른 지점 파일을 넣으면 직원마다 403 이 난다.
설치 뒤에 확인할 수 있다.

```powershell
Get-Content C:\HiFIS\config.json
```

### 5. 실행하고 로그 창을 띄운다

```powershell
schtasks /run /tn "HiFIS 출퇴근"
Get-Content C:\HiFIS\scan.log -Wait -Tail 20
```

`COM3 연결됨` 이 떠야 한다. 이 창은 **닫지 말고 그대로 둔다.**

### 6. 폰에서 그 지점 계정으로 로그인

TestFlight 의 HiFIS → 그 지점 **트레이너 계정** (아래 목록) → 상단 **바코드 버튼**.
화면 밝기를 올린다.

### 7. 바코드를 스캐너에 댄다

로그 창에 이렇게 떠야 한다.

```
2026-08-07 14:03:25  2026-0007 출근
```

**여기까지 뜨면 그 지점은 끝이다.** `Ctrl+C` 로 로그 창만 닫는다 —
프로그램은 계속 돈다.

### 안 될 때 로그에 뜨는 것

| 줄 | 뜻 | 할 일 |
|---|---|---|
| `Try 문에 해당 Catch 블록이 없습니다` 등 문법 에러 무더기 | **한글이 깨졌다** (아래) | BOM 을 붙인다 |
| `스캐너를 못 가렸습니다 — 붙어 있는 포트: …` | 2번이 안 먹었다 | `USB CDC` 다시 읽히기 |
| `실패 (403)` | 다른 지점 직원 | 그 지점 계정으로 로그인했는지 확인 |
| `실패 (401)` | 토큰 문제 | 그 지점 설치 파일이 맞는지 확인 |
| `실패 (404)` | 없는 사번 | 그 계정이 운영에 있는지 확인 |
| 아무것도 안 뜸 | 스캐너를 못 찾는 중 | 5초마다 다시 본다 — 3번부터 |

### 한글이 깨져서 파일 전체가 문법 에러가 날 때

**Windows PowerShell 5.1 은 `.ps1` 에 UTF-8 BOM 이 없으면 UTF-8 로 안 읽는다.**
한국어 윈도우에서는 CP949 로 읽어서 주석의 한글이 `遺숈씤??` 처럼 깨지고,
깨진 바이트가 따옴표를 먹어 **파일이 통째로 파싱 에러**가 난다.
파일 크기는 정상이라 눈으로는 멀쩡해 보인다 (2026-08-07 화순점에서 실제로 겪었다).

`scan.ps1` 에 BOM 을 붙여 뒀으므로 지금 받은 파일은 안 걸린다. 옛 파일로 이미
설치했다면 **그 자리에서 고칠 수 있다** — 내용은 맞고 앞 3바이트만 없는 것이다.

```powershell
$c = [IO.File]::ReadAllText('C:\HiFIS\scan.ps1', [Text.Encoding]::UTF8)
[IO.File]::WriteAllText('C:\HiFIS\scan.ps1', $c, (New-Object Text.UTF8Encoding $true))
```

> 도구를 고칠 때 **BOM 을 떼지 않는다.** `발급.py` 는 `scan.ps1` 을 바이트 그대로
> 실어 보내므로, 레포의 그 파일에 BOM 이 있어야 센터 PC 에서도 있다.

## 가장 쉬운 길 — 붙여넣기 한 번

센터 PC 에는 Git 도 USB 도 없을 수 있다. **파일을 옮길 필요 없이** 개발 맥에서
덩어리를 만들어 가서, 센터 PC 의 관리자 PowerShell 에 통째로 붙여넣으면 끝난다.

```bash
python3 tools/scan/발급.py
```

지점을 고르면 `설치-<지점>.ps1.txt` 가 만들어진다. **그 파일 내용 전체**를
센터 PC 의 **관리자 PowerShell** 에 붙여넣으면

- `C:\HiFIS\scan.ps1` · `C:\HiFIS\config.json` 이 만들어지고
- 작업 스케줄러 등록까지 된다

붙여넣기 전에 **관리자 권한**인지 확인한다 (`시작 → PowerShell 우클릭 →
관리자 권한으로 실행`). 스케줄러 등록에 필요하다.

### 붙여넣은 다음 — 눈으로 확인

스케줄러로 도는 것은 **창이 안 보인다.** 로그를 실시간으로 따라가며 본다.

```powershell
schtasks /run /tn "HiFIS 출퇴근"
Get-Content C:\HiFIS\scan.log -Wait -Tail 20
```

`-Wait` 라 창이 안 닫히고 계속 지켜본다. 그 상태에서 바코드를 대면

```
2026-08-07 14:03:11  COM3 연결됨
2026-08-07 14:03:25  2026-0013 출근      ← 바로 이 줄이 뜬다
```

`Ctrl+C` 로 이 창만 닫는다 — **프로그램은 계속 돈다** (구경만 하는 창이다).

> 스크립트를 base64 로 실어서 여러 줄로 쪼개 두었다 — 윈도우 콘솔은 한 줄이
> 8192자를 넘으면 잘라 버린다.

아래는 손으로 하나씩 할 때의 절차다.

---

## 1. 단말 토큰 발급 (대표 계정으로 한 번)

지점마다 하나씩 만든다. **토큰은 발급 직후 한 번만 보인다** — 서버는 해시만
들고 있어서 다시는 못 보여준다. 놓치면 폐기하고 새로 발급한다.

```bash
# 지점 id 확인
curl https://api.hifis.app/branches -H "Authorization: Bearer <대표 토큰>"

# 발급
curl -X POST https://api.hifis.app/scan-terminals \
  -H "Authorization: Bearer <대표 토큰>" -H 'Content-Type: application/json' \
  -d '{"branchId":"<지점 id>","name":"화순점 카운터"}'
```

응답의 `token` 이 그 값이다 (`hifis_term_...`).

> **이 토큰으로 할 수 있는 일은 그 지점 출퇴근 찍기뿐이다.** 다른 API 는 전부
> 401 이고, 다른 지점 직원을 찍으면 403 이다. 그래서 파일에 그냥 둬도 된다.

## 2. 스캐너를 COM 모드로

스캐너 설명서의 설정 바코드를 **읽히면** 된다 (기기에 인쇄된 종이).

| 항목 | 고를 것 |
|---|---|
| Interface Setting | **USB CDC** |
| Terminator Suffix | `<Data><LF>` 또는 `<Data><CR><LF>` |

`USB keyboard` 를 읽히면 언제든 되돌아간다.

**꽂고 확인** — 관리자 PowerShell 에서

```powershell
[System.IO.Ports.SerialPort]::GetPortNames()
```

`COM3` 같은 게 나오면 된 것이다. 안 나오면 장치 관리자에서 어디에 잡혔는지 본다.

## 3. 파일 복사

`C:\HiFIS\` 를 만들고 아래 둘을 넣는다.

```
C:\HiFIS\scan.ps1
C:\HiFIS\config.json
```

`config.json` 은 `config.example.json` 을 복사해서 토큰만 채운다.

```json
{
  "apiBase": "https://api.hifis.app",
  "terminalToken": "hifis_term_..."
}
```

## 4. 한 번 직접 돌려 본다

스케줄러에 걸기 전에 눈으로 확인한다.

```powershell
powershell -ExecutionPolicy Bypass -File C:\HiFIS\scan.ps1
```

`COM3 연결됨` 이 뜨고, 폰 바코드를 대면 `2026-0013 출근` 이 찍혀야 한다.
`Ctrl+C` 로 종료.

## 5. 자동 실행 등록 (한 번만)

**관리자 PowerShell** 에서 한 줄이다.

```powershell
schtasks /create /tn "HiFIS 출퇴근" /sc onstart /ru SYSTEM /rl HIGHEST /f `
  /tr "powershell -WindowStyle Hidden -ExecutionPolicy Bypass -File C:\HiFIS\scan.ps1"
```

- `/sc onstart` — **컴퓨터를 켤 때** 뜬다. 윈도우 로그인도 필요 없어서
  **아무도 로그인 안 한 아침에도 첫 출근자가 찍을 수 있다.**
- `/ru SYSTEM` — 사람 계정과 무관하게 돈다
- `-WindowStyle Hidden` — 창이 안 보인다
- 컴퓨터를 끄면 같이 꺼진다. 따로 할 것이 없다

**한 번 등록하면 끝이다.** 껐다 켜도 매번 저절로 돈다.

지금 바로 시작시키려면:

```powershell
schtasks /run /tn "HiFIS 출퇴근"
```

## 확인·문제 해결

| 보고 싶은 것 | 명령 |
|---|---|
| 등록됐나 | `schtasks /query /tn "HiFIS 출퇴근"` |
| 돌고 있나 | `Get-Process powershell` |
| 무슨 일이 있었나 | `Get-Content C:\HiFIS\scan.log -Tail 30` |
| 서버가 보기에 살아 있나 | `GET /scan-terminals` 의 `lastUsedAt` |

**로그에 남는 것**

```
2026-08-07 09:12:03  시작 — 서버 https://api.hifis.app
2026-08-07 09:12:03  COM3 연결됨
2026-08-07 09:15:41  2026-0013 출근
2026-08-07 18:02:19  2026-0013 퇴근
2026-08-07 18:02:24  2026-0013 — 중복이라 건너뜀
```

**안 찍힌다고 하면 이 순서로 본다.**

1. 로그에 그 시각 줄이 있나 → 없으면 스캐너·포트 문제
2. `실패 (403)` 이면 → 다른 지점 직원이다
3. `실패 (401)` 이면 → 토큰이 폐기됐거나 틀렸다
4. `실패 (404)` 이면 → 등록되지 않은 사번이다

> **직원 폰에서도 확인된다.** 바코드를 띄운 채로 찍으면 폰에 `출근했어요` 가
> 뜨고 바코드가 저절로 닫힌다. 그게 안 뜨면 안 찍힌 것이다 — 스캐너는 앱이
> 돌든 말든 초록불이 들어오고 삑 소리가 나므로, 소리만으로는 알 수 없다.

## 생존 신호 — 이제 대표 폰이 먼저 안다 (2026-08-26)

**옛 버전은 조용히 죽었다.** 프로그램이 안 돌면 읽은 값이 PC 밖으로 못 나가고,
서버에는 성공도 실패도 안 남아서 **아무도 안 찍은 것과 구별이 안 됐다.**
저녁이 되면 결근 알림이 나가서 그날 나온 사람이 안 나온 것처럼 보였다
(2026-08-26 화순에서 실제로 그럴 뻔했다).

그래서 이 프로그램이 **자기가 살아 있다고 따로 말한다.**

| 언제 | 보내는 것 |
|---|---|
| 프로그램이 뜰 때 | `POST /scan-terminals/startup` — 활동 기록에 남는다 |
| 5분마다 | `POST /scan-terminals/heartbeat` — 지금 잡은 포트를 같이 보낸다 |
| 포트를 막 잡았을 때 | 하트비트 한 번 (다음 주기를 안 기다린다) |

서버는 이걸로 **무엇이 죽었는지까지 갈라서** 대표에게 알린다.

| 서버가 보는 것 | 대표 폰에 뜨는 말 |
|---|---|
| 신호가 아예 없음 | 스캔이 한 건도 없어요 (단말 상태를 알 수 없어요) |
| 하트비트가 멎음 | 카운터 PC 가 꺼져 있거나 프로그램이 안 돌고 있어요 |
| 신호는 오는데 포트 null | 프로그램은 도는데 스캐너를 못 찾고 있어요 |
| 다 정상인데 스캔만 없음 | **안 알린다** — 고장이 아니라 아무도 안 온 것이다 |

- **`scan.ps1` 을 새로 깔아야 채워진다.** `config.json` 은 안 바꿔도 된다.
  안 깐 단말은 첫 줄(`상태를 알 수 없어요`)로 뜬다.
- **하트비트는 `마지막 사용` 시각을 안 민다.** 그 값은 계속 "사람이 찍은 시각"
  이어야 한다 — 같이 밀면 아무도 안 찍은 날에도 방금 찍은 것처럼 보인다.
- 신호가 실패해도 프로그램은 그냥 돈다. 곁다리라서 여기서 막히면 정작
  출퇴근이 안 찍힌다.

## 폐기

PC 를 바꾸거나 토큰이 샜으면 폐기한다. 즉시 401 이 된다.

```bash
curl -X POST https://api.hifis.app/scan-terminals/<id>/revoke \
  -H "Authorization: Bearer <대표 토큰>"
```
