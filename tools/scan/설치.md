# 지점 출퇴근 스캐너 설치

지점 카운터 PC 에 **화면 없이** 도는 프로그램을 얹는다. HiFIS 앱을 켜 둘 필요가
없다 — 그 PC 는 회원 등록 등에 같이 쓰는 공용 컴퓨터라, 사람 계정으로 켜 두면
누구나 급여·사내톡·조직도를 들여다볼 수 있고 MASTER 로 켜 두면 모니터링까지 열린다.

**설치할 것이 없다.** 윈도우에 기본으로 있는 PowerShell 로 돈다 —
Flutter 도 Git 도 필요 없다.

---

## 1. 단말 토큰 발급 (대표 계정으로 한 번)

지점마다 하나씩 만든다. **토큰은 발급 직후 한 번만 보인다** — 서버는 해시만
들고 있어서 다시는 못 보여준다. 놓치면 폐기하고 새로 발급한다.

```bash
# 지점 id 확인
curl https://api.hifis.app/branches -H "Authorization: Bearer <대표 토큰>"

# 발급
curl -X POST https://api.hifis.app/scan-terminals \
  -H "Authorization: Bearer <대표 토큰>" -H 'Content-Type: application/json' \
  -d '{"branchId":"<지점 id>","name":"화순점 카운터"}'
```

응답의 `token` 이 그 값이다 (`hifis_term_...`).

> **이 토큰으로 할 수 있는 일은 그 지점 출퇴근 찍기뿐이다.** 다른 API 는 전부
> 401 이고, 다른 지점 직원을 찍으면 403 이다. 그래서 파일에 그냥 둬도 된다.

## 2. 스캐너를 COM 모드로

스캐너 설명서의 설정 바코드를 **읽히면** 된다 (기기에 인쇄된 종이).

| 항목 | 고를 것 |
|---|---|
| Interface Setting | **USB CDC** |
| Terminator Suffix | `<Data><LF>` 또는 `<Data><CR><LF>` |

`USB keyboard` 를 읽히면 언제든 되돌아간다.

**꽂고 확인** — 관리자 PowerShell 에서

```powershell
[System.IO.Ports.SerialPort]::GetPortNames()
```

`COM3` 같은 게 나오면 된 것이다. 안 나오면 장치 관리자에서 어디에 잡혔는지 본다.

## 3. 파일 복사

`C:\HiFIS\` 를 만들고 아래 둘을 넣는다.

```
C:\HiFIS\scan.ps1
C:\HiFIS\config.json
```

`config.json` 은 `config.example.json` 을 복사해서 토큰만 채운다.

```json
{
  "apiBase": "https://api.hifis.app",
  "terminalToken": "hifis_term_..."
}
```

## 4. 한 번 직접 돌려 본다

스케줄러에 걸기 전에 눈으로 확인한다.

```powershell
powershell -ExecutionPolicy Bypass -File C:\HiFIS\scan.ps1
```

`COM3 연결됨` 이 뜨고, 폰 바코드를 대면 `2026-0013 출근` 이 찍혀야 한다.
`Ctrl+C` 로 종료.

## 5. 자동 실행 등록 (한 번만)

**관리자 PowerShell** 에서 한 줄이다.

```powershell
schtasks /create /tn "HiFIS 출퇴근" /sc onstart /ru SYSTEM /rl HIGHEST /f `
  /tr "powershell -WindowStyle Hidden -ExecutionPolicy Bypass -File C:\HiFIS\scan.ps1"
```

- `/sc onstart` — **컴퓨터를 켤 때** 뜬다. 윈도우 로그인도 필요 없어서
  **아무도 로그인 안 한 아침에도 첫 출근자가 찍을 수 있다.**
- `/ru SYSTEM` — 사람 계정과 무관하게 돈다
- `-WindowStyle Hidden` — 창이 안 보인다
- 컴퓨터를 끄면 같이 꺼진다. 따로 할 것이 없다

**한 번 등록하면 끝이다.** 껐다 켜도 매번 저절로 돈다.

지금 바로 시작시키려면:

```powershell
schtasks /run /tn "HiFIS 출퇴근"
```

## 확인·문제 해결

| 보고 싶은 것 | 명령 |
|---|---|
| 등록됐나 | `schtasks /query /tn "HiFIS 출퇴근"` |
| 돌고 있나 | `Get-Process powershell` |
| 무슨 일이 있었나 | `Get-Content C:\HiFIS\scan.log -Tail 30` |
| 서버가 보기에 살아 있나 | `GET /scan-terminals` 의 `lastUsedAt` |

**로그에 남는 것**

```
2026-08-07 09:12:03  시작 — 서버 https://api.hifis.app
2026-08-07 09:12:03  COM3 연결됨
2026-08-07 09:15:41  2026-0013 출근
2026-08-07 18:02:19  2026-0013 퇴근
2026-08-07 18:02:24  2026-0013 — 중복이라 건너뜀
```

**안 찍힌다고 하면 이 순서로 본다.**

1. 로그에 그 시각 줄이 있나 → 없으면 스캐너·포트 문제
2. `실패 (403)` 이면 → 다른 지점 직원이다
3. `실패 (401)` 이면 → 토큰이 폐기됐거나 틀렸다
4. `실패 (404)` 이면 → 등록되지 않은 사번이다

> **직원 폰에서도 확인된다.** 바코드를 띄운 채로 찍으면 폰에 `출근했어요` 가
> 뜨고 바코드가 저절로 닫힌다. 그게 안 뜨면 안 찍힌 것이다 — 스캐너는 앱이
> 돌든 말든 초록불이 들어오고 삑 소리가 나므로, 소리만으로는 알 수 없다.

## 폐기

PC 를 바꾸거나 토큰이 샜으면 폐기한다. 즉시 401 이 된다.

```bash
curl -X POST https://api.hifis.app/scan-terminals/<id>/revoke \
  -H "Authorization: Bearer <대표 토큰>"
```
